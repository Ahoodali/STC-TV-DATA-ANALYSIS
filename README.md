# STC TV Data Analysis & Machine Learning

## Project Overview
This project focuses on analyzing STC TV viewing data and using machine learning techniques to generate insights and recommendations that can help improve the user experience.

## Project Objectives
- Analyze user viewing behavior and identify key patterns.
- Forecast watch time for the upcoming months.
- Build a recommendation system based on users' viewing preferences.
- Generate the top 5 recommendations for users who watched "Moana".
- Present the findings using data storytelling.

## Main Tasks

### 1. Data Analysis
Analyzed viewing behavior, content preferences, video quality, and watch time patterns.
`![program](لقطة شاشة 2026-08-15 100053.png) `

### 2. Time Series Forecasting
Used historical watch-time data to forecast expected viewing activity for the upcoming months.

### 3. Recommendation System
Built a recommendation approach using users' viewing behavior and preferences to suggest relevant programs.

### 4. Data Storytelling
Presented the key findings, insights, and recommendations in a PowerPoint presentation.

## Key Outcome
The project demonstrates how data analysis, forecasting, and recommendation systems can be used to transform viewing data into actionable insights and support improvements in the STC TV user experience.
